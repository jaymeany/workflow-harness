# Workflow harness

A set of folders and files that runs a small team of Claude Code agents on a software project.

Each agent has one job and one column on a Trello board:

- **Orchestrator** plans the work and writes the cards.
- **Research** documents what exists and what a card needs.
- **Designer** builds the surfaces.
- **Dev** writes the code.
- **QA** checks the work and moves cards to Done.

Hooks keep each agent in its lane.
